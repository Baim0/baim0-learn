# baim0-learn

运维 / 后端技术学习笔记，涵盖云原生、可观测性、网络及 AI 等方向。

## 内容概览

### Kubernetes
Kubernetes 基础概念、集群安装部署、日常运维技巧（descheduler、CoreDNS、IPVS 调优等）、生产排障经验。

- [Kubernetes 基础笔记](kubernetes/) — 从安装到核心概念
- [K8s 技巧与经验](k8sFunny/) — 集群整理、Terminating 命名空间处理、YAML 美化等
- [K8s 排障记录](k8sTrouble/) — 数据不一致等线上问题

### ELK 日志栈
从架构设计到实战案例，完整覆盖 Elasticsearch、Logstash、Kibana、Filebeat 及 Kafka/ZooKeeper 的集成。

- 集群部署与调优
- 日志收集、过滤、可视化全链路
- 实战案例：Apache、Nginx、MySQL 慢查询、Tomcat
- 日志订阅到 HDFS、Zabbix 告警集成

### Nginx
从入门到进阶的完整学习路径，涵盖反向代理、负载均衡、HTTPS、Lua 扩展、安全加固、监控及 Jenkins 自动化集成。

### Prometheus
Prometheus 监控体系：指标类型、PromQL、查询技巧、服务发现。

### 网络
TCP 协议详解、mtr 路由诊断、tcpdump 抓包分析、Linux 路由配置。

### AI
大模型（LLM）相关：MCP 协议概念、n8n 工作流自动化。

### 其他
- K8s 离线安装
- FRP 内网穿透
- Ollama 本地大模型搭建
